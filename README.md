## Password Cracking Projects

This repository documents my Week 3 practical projects during the Networkwalks Cybersecurity and Ethical Hacking Internship.

The focus of this week's activities was understanding password cracking, PDF hash extraction, dictionary attacks, and password recovery.

## 📌 Project Modules

### Module 1: Password Cracking with John the Ripper (JTR)

**Tools Used:**
- Kali Linux
- John the Ripper 1.9.0 Jumbo
- pdf2john
- Password wordlists

**Practical Activities:**
1. Verified John the Ripper installation.
2. Extracted the password hash from an encrypted PDF using pdf2john.
3. Saved the extracted hash in a text file.
4. Performed a dictionary attack using John's password.lst.
5. Retrieved the recovered password using `john --show`.

**Result:** Successfully recovered the PDF password.

### Module 2: Password Cracking with Networkwalks Tools

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Chromium Browser
- Kali Linux

**Practical Activities:**
1. Uploaded the encrypted PDF to the Networkwalks Hash Calculator.
2. Extracted the PDF hash.
3. Submitted the hash to the Networkwalks Password Cracker.
4. Tested the default dictionary.
5. Created and uploaded a custom wordlist after the initial dictionary failed.
6. Successfully matched the recovered password.

**Result:** Successfully completed the custom-wordlist exercise.
